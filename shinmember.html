真のメンバー紹介

HASEGAWA // VOICE ERROR
バンドの発声担当。
ライブ中に突然現実認識がズレる。
マイクより先に空間を揺らす。
最近は自分の影とセッションしている。
たぶん一番危ない。
BASS UNIT // 404 GROOVE
ベース担当だが実体は不明。
音だけが先に届く現象が確認されている。
低音域でのみ人格が成立。
たまに人間のフリをする。
たぶん一番重い。
DRUM CORE // KAMIKAZE PULSE
時間を刻む装置。
BPMが感情に連動している。
速すぎると現実が飛ぶ。
遅すぎると記憶が戻る。
たぶん一番危険。
SYSTEM // UNKNOWN GUITAR
ギター担当（とされている）。
ただし誰も弾いている瞬間を見ていない。
ノイズだけが存在証明。
アンプが本体説あり。
たぶん一番いない。
